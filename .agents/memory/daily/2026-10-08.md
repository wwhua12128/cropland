## 两个真实 Windows 兼容 bug（osm_roads.py，Linux 从未暴露）
1. cache_path() 用 `src.startswith("/")` 判文件图层 → Windows 盘符路径返回
   None → 道路缓存落到 %TEMP% 兜底 + 自动回退失效。改 os.path.isfile 通吃。
2. save_roads() 对已存在缓存 os.remove → Windows 下文件被打开的 OGR 层占用即
   PermissionError 崩（实测：用户本机 QGIS 会话长期锁着 %TEMP%\osm_道路.gpkg）。
   加锁退让：落旁路文件 osm_道路_N.gpkg，调用方按返回值加载不受影响。
- 新增回归：test_workbench_bae T9b（Windows-only：占住句柄验证旁路落盘）。

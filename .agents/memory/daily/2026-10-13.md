## 教训
- **PS 5.1 读 UTF-8 无 BOM 的 .ps1 会按 ANSI 解码**，中文脚本直接 ParserError
  （与 `Set-Content -Encoding utf8` 写 BOM 是同一个坑的两面）：临时 .ps1 一律写
  纯 ASCII，或用 pwsh 7 执行。
- 改 `QGIS4.ini` 必须在 QGIS 关闭时做，否则退出时被内存态覆盖。

## 追加：真实 bug —— 渔网里的空要素让工作台打不开（v0.10.3）

花花的报障原文（QGIS 消息日志 WARNING）链路：
`plugin.run_annotate` → `AnnotateDock.__init__` → `setup_ui` → `_sync_ui`
→ `refresh_progress` → `wb._grid_cells` → `_cell_id` →
`ValueError: Null geometry cannot be converted to a point`。

- 根因：她的渔网层里混进了**没有几何的要素**（手滑建的空要素），
  `_cell_id` 无条件 `geom.centroid()` 就炸；异常从 `AnnotateDock.__init__`
  抛出 → dock 根本没建出来 → 用户视角是"点了工作台没反应/插件好像没装"。
  之前排查中被"插件管理器的勾选框=启用/停用"这条岔路带偏了一阵。
- 修复（3 处）：
  1. `_cell_id`：空/None/空几何返回 `None`；
  2. `_grid_cells`：跳过空几何要素（并跳过 cid 为 None 的），空格不进导航/进度；
  3. `setup_ui`：`_sync_ui()` 包 try/except，界面初始化异常写进工作台日志而不是
     让整个 dock 构建失败；`plugin.run_annotate` 同步加 try/except → 弹窗提示
     （镜像 `run()` 里已有的做法）+ 取消菜单勾选，避免"勾着却打不开"的死循环。
- 回归：`tests/test_workbench_bae.py` 新增 T13（内存渔网层混一个空要素，
  断言 `_grid_cells` 只返回 1 格、`_cell_id` 返回 None 而不抛异常）。
  全套 6 个 suite 重跑：17+18+6+13+14+qа 全绿。
- 顺手修：`metadata.txt` 的 `name` 字段是**双重编码乱码**
  （UTF-8 中文被当 GBK 再存），已还原为 `Cropland Delineator 耕地标注工作台`
  （首提交 ca33f36 里本来只有英文名，中文是后来加的）。版本 0.10.2 → 0.10.3。

- 提交：`6d5da2a`（6 文件），已推 fork `wwhua12128/cropland`。

# 2026-10-14 磁力切分"收束甩尾"根因与 v0.10.4 修复

第三人称事件日志（写给没有共同历史的未来读者）。

## 报障
花花（wwhua12128）原话：*"在实际切分过程中，会在最后一点收束点击之后又沿着
结束的那个点向外直线切割其他多边形"* —— 此问题在 v0.10.2 的"按端点所在地块
判界"修复后**仍然存在**。

## 定位（用她自己的台账，不改她的数据）
数据：`E:\work\江西省\吉安市\永新县\YF1.gpkg`（EPSG:4547，195 个要素，1 个带洞，
GEOS 非法 0 个）＋ 侧车台账 `YF1_ops.jsonl`（1502 行；split 30 条）。

- 台账里的 split 行存的正是**外推后的线**（`apply_split(line_layer.asWkt())`），
  所以末段长度＝当次外推尾巴长度：实测 **20~2271 m**（seq 52=2271、seq 50=1567、
  seq 75=1588、seq 74=1531、seq 107=170）。两端各恰好 2 段共线 → 末段就是尾巴。
- 她这一格（`永新县_3_5`）是**公里级**：最大地块 3.5 km²、包围盒 2826×3213 m、
  195 块挤在一格。锚点离地块边界本来就远，尾巴长有其必然性。
- 但旧实现"探到界外后再多走**一整步**"会在必要长度之外多甩：步长 `max(pixel*2,10)`
  起步、走满 `step*80` 后翻倍加速到 `step_cap=64` → 收笔尾巴实际多出 10~64+10 m；
  加速段还会**一步跨过界外的窄缝或窄条田**，尾巴于是直着扫穿邻块。
- 语义实测（QGIS 4.2.2，1000×1000 方块）：两端都在界外 → `rc=0` 且面积精确；
  **两端只越外 0.2 m → 照样 `rc=0`**（0.2 m 足够）；一端在内 → `rc=1000` 切不开。
  新发现两条：
  1. **带洞（内环）的多边形，线端落在洞里切不开**（`rc=1000`）——QGIS 只认
     "越过**外环**"的线端，洞里它当"还在多边形内"。从洞里出发到外环外也切不开。
  2. **QGIS 4 删掉了 `QgsGeometry.boundary()`**（要用
     `QgsGeometry(geom.constGet().boundary())`）——第一版精确外推因此静默退回
     采样兜底，差点以为"精确解和采样解一样"。

## 修复（v0.10.4）
1. `lasso.grow_ends()` 新增 `escape` / `escape_end` 回调：给得出"沿该方向到边界
   的第一个交点距离"就直接用它，只越 `eps = max(step*0.02, 1e-9)`（≈0.2 m）。
   拿不到时退回采样：粗探（可加速）＋ **step/8 细查一遍**（防跨缝）＋ 24 次二分
   （`probe_exit`）。
2. `map_tools._grow_out()` 用 `ray ∩ owner.boundary()` 量这个距离（owner＝包含该
   端点的地块并集，多块用 `unaryUnion`）。尾巴因此**严格止于锚点所在地块边界外
   一丝**，不可能再横穿任何邻块。
3. 线端落在挖除留下的洼地（洞）里时 `apply_split` 会一处都切不开：`_do_finish`
   此时**退一步**用 `outer=True`（只取外环）重切一次并记日志
   `[磁力] 线端落在洞里（挖除的洼地），已延到地块外沿再切`。`apply_split` 改为
   返回切开处数以便判断（向后兼容）。

## 教训
- 判断"尾巴该多长"要看**几何必需量**（锚点到所在地块边界的距离），不是步长；
  固定"多走一步"在大地块/加速步长下就是肉眼可见的一条直线。
- 台账里存的就是落地几何，是排查这类"多出来的线"最直接的证据源。
- QGIS 4 API 有删改，别凭 QGIS 3 记忆调 API：静默退回的兜底分支会让"修复没生效"
  看起来像"修复无效"。
